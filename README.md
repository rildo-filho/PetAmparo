# PetAmparo

Sistema web proposto para apoiar uma ONG de proteção animal no registro de animais resgatados, adotantes, adoções e doações.

## Contexto
Projeto desenvolvido para o Projeto Integrador Extensionista I (PIE I) do curso de Análise e Desenvolvimento de Sistemas.

## Objetivo
Centralizar informações que hoje estariam dispersas em planilhas, formulários e mensagens, reduzindo retrabalho e melhorando o acompanhamento dos processos de resgate, adoção e doação.

## Stack planejada
- Frontend: HTML5, CSS3, JavaScript e Bootstrap
- Backend: Python, Django e Django REST Framework
- Banco de dados: PostgreSQL
- Autenticação: JWT e permissões por perfil
- Versionamento: Git e GitHub

## Estrutura prevista
- `/docs`: documentação do projeto
- `/backend`: backend Django
- `/frontend`: interface web
- `/database`: esquema e scripts do banco

## ONG parceira
Instituto PetAmparo (fictícia) - Campinas, SP, Brasil.
